## conceptual

- Read CLAUDE.md to get an idea of how it works, but things may be out of date.
- ideas/ has old ideas. it's 2 paths for a wasm host: raycart/ is emscripten-based, and gl/ is all implemented in host (glfw and a little opengl.) What I really want is something more like gl/ (full host API implemented in web js) but with raylib API, but may be an unrealistic amount of work
- I'm not sure we can get through all of them in 1 context, but take them 1-by-1 and get them perfect.
- I am trying to avoid using emscripten here, but maybe it could be used for the web-host implementation? still try to keep it small & fast and don't use asyncify. This is not ideal, but if it's too much work, it might get us going.

## issues in current host (host/web/raylib.js)

- GetMonitorWidth / GetMonitorHeight refs screen, which is not defined.
- many raylib functions are not defined, many are just stubs. I want a complete implementation, even if it takes a long time.
- DrawText is not right font
